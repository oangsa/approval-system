# Acceptance Criteria — Issue #13: Comments & Private Attachments

**Feature:** `O01` Comments / Discussion (`FR-041`, `AC-041`) and `O02` File Attachments (`FR-042`, `AC-042`)  
**Status:** Locked in Phase 0 before source implementation; verification status tracked in [verification.md](verification.md).  
**Authorities:** [Product Specifications](../../specs/specifications.md), [SRS](../../specs/srs.md), [API Specs](../../specs/api-specs.md), [UI Specs](../../specs/ui-specs.md), [Test Spec](../../specs/test.md), [SDS](sds.md), [ADR-13](../../adr/ADR-13-gcs-private-attachment-storage.md).

---

## 1. Parent Frozen Acceptance Criteria

- **AC-041 (`O01`, `FR-041`):** A permitted participant can post a comment, see persisted content, and cannot use commenting to record a formal decision or bypass visibility.
- **AC-042 (`O02`, `FR-042`):** Permitted uploads/downloads work through authorized private storage; disallowed types, oversize files, and cross-request access are denied.

## 3. Private Attachments (`ATT-AC-01` – `ATT-AC-09`)

| `ATT-AC-01` | `AC-042` | `FR-042`, `BR-060`, API §§5.7, 6.7, ADR-13 | Authenticated request owners on `DRAFT` or `RETURNED` requests can upload supported files (`application/pdf`, `image/png`, `image/jpeg`, `image/webp`, `text/plain`, size `1..10485760` bytes, max `10` files per working revision) via `multipart/form-data` `POST /api/v1/requests/:id/attachments` (`201 AttachmentDTO` + `Location` + `Cache-Control: no-store`). | `ATT-AC-02` | `AC-042` | `BR-060`, `BR-072`, API §2.4, `FT-042` | Oversize files (`> 10 MiB`) fail with `413 FILE_TOO_LARGE`; unsupported MIME types, disallowed extensions, SVG/HTML/executable uploads, and disguised magic-byte mismatches fail with `415 UNSUPPORTED_MEDIA_TYPE`; zero-byte files, invalid filenames, per-revision cap excess, and invalid multipart/query inputs fail with `422 VALIDATION_ERROR` or `400 BAD_REQUEST`. Rejections occur **before** object storage commit and return safe errors without stack traces or storage keys. | `ATT-UT-03..07`, `ATT-API-05..08`, `ATT-UI-07..08` |
