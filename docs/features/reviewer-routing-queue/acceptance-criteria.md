# Reviewer routing and queue acceptance criteria

The Issue #4 slice is implemented. Verification is partial where the STS identifies missing assertions; REV-AC-06 remains a downstream dependency. Parent requirements remain authoritative; passing an isolated child does not close a dependent journey. See [STS](sts.md) and [verification](verification.md).

1. **REV-AC-01 — M07 / FR-007 / AC-007:** On accepted submission, all required eligible reviewer slots in every required stage resolve from trusted policy and department in the same transaction. One or two stages and parallel required slots retain their correct initial states. Missing, inactive, wrong-role or self-only configuration returns `409 CONFIGURATION_INCOMPLETE` and leaves no partial submission, cycle, slots, audit or outbox.
2. **REV-AC-02 — M08 / FR-008 / AC-008:** An active assigned REVIEWER sees only their own actionable slots in the active stage and current cycle of PENDING requests. WAITING, terminal, stale, foreign and former assignments do not appear; role and assignment changes take effect on current reads.
3. **REV-AC-03 — M08:** Search and task detail use the frozen direct DTO, pagination and error contracts. Anonymous and wrong-role access is denied; foreign and missing task IDs are indistinguishable. Neither client filters nor Administrator-only membership widens access.
4. **REV-AC-04 — M08:** The queue and read-only task detail show only authorized context, with accessible desktop and mobile presentations, distinct loading/empty/error states, retry, keyboard support and account-switch clearing. No decision action is fabricated.
5. **REV-AC-05 — M13 / FR-012 / AC-012:** Submission rejects self-only assignment, including stacked roles. A reusable server guard rejects self-decision using trusted current actor and locked task/request identity, without exposing foreign tasks. Guard tests alone do not prove the direct API acceptance criterion.
6. **REV-AC-06 — dependent:** Issue #5 integrates the guard into its actual decision transaction and proves direct self-vote returns `403 SELF_APPROVAL_FORBIDDEN` with no decision, transition, audit or outbox change. Full AC-012 and its direct-decision journey remain blocked until that evidence exists. Future delegation and bulk paths must also enforce the invariant.
