# Issue #11 system design

Status: preimplementation design. Baseline `bdab39b115e39caec46da099ee9956cf47567423`, branch `feature/11-sprint-2-full-stack-reporting-dashboards-timeline`. Frozen authority: specifications.md and srs.md FR-018/029/030, BR-033/054/057/068/071/073, AC-018/029/030; system-sds.md; api-specs.md §§2.3, 4, 6.8–6.9; ui-specs.md §§4, 6, 12; test.md; traceability.md; sprint-2.md. Styling, lookup and filter/search guidelines apply. This design refines their selected M16, R15 and R16 behavior; it does not authorize extra routes or grants.

Reports scope is the deduplicated union of own requests and requests currently readable by a pending reviewer other than their requester: current cycle and revision, ACTIVE stage, ACTIONABLE slot. Use EXISTS, not multiplying joins. Administrators get organization-wide aggregate counts only; this grants no private request detail. Former handled-only access does not grant report scope. OUTCOME counts each current terminal APPROVED, REJECTED or WITHDRAWN request once; RETURNED belongs under STATUS. Filter, group, count and page within a repeatable snapshot using a single CTE for group count/page. Dashboard is read-only repeatable-read and query service rechecks identity. No migration is expected.

Dashboard sections are composed only for the authenticated user's actual roles. All queries use server authority; no role parameter. Overdue means server `now >= dueAt` for a current pending actionable slot in an ACTIVE stage. Lists are capped at five with stable ordering. Delegation and notification properties are omitted until their producers exist; they are not fabricated as zero. Recent decisions link to `/reviews/:taskId` without widening RequestService.Readable. Administrator data contains aggregate and configuration counts, never private request links.

Timeline reuses DecisionRepository.Timeline and immutable audit records. Project only event-specific safe metadata; order by occurredAt then id, preserve actor/time/cycle/revision, and use the existing Bangkok formatter. Do not fabricate history.
