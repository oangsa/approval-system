## PR #88 Blocking Findings Resolved (`B01`–`B06`)

1. **`B01` — Runtime stored-definition validation (`apps/api/src/Domains/Requests/RequestRules.ts`, `RequestService.ts`, `RequestRoutes.ts`):** Added `assertPublishedDefinition()` validating stored `PublishedRequestType` records with both `publishedRequestTypeSchema` (Zod) and `validateRequestTypeDefinition()` (semantic graph/constraint rules) plus `typeId`/`versionId` identity checks across `Type`, `Types`, `TypeVersion`, `create`, `patch`, `submit`, `validateContent`, `editableContent`, and `resolvePlan`. Invalid or cyclic stored definitions fail with `409 CONFIGURATION_INCOMPLETE` and zero database mutation.
2. **`B02` — Explicit null/empty/whitespace field validation (`packages/contracts/src/requests.ts`):** Updated `validateFields()` to distinguish omitted keys (`!hasOwnField` or `undefined`) from explicitly supplied invalid values (`null`, `""`, whitespace-only strings), returning `422 VALIDATION_ERROR` (`INVALID_VALUE`) for visible fields and `422 FORM_FIELD_NOT_APPLICABLE` for hidden fields while preserving incomplete draft creation/editing when optional/unanswered fields are omitted.
3. **`B03` — Own-property and prototype-free field evaluation (`packages/contracts/src/requests.ts`, `RequestRules.ts`, `RequestWizard.tsx`, `RequestTypePreview.tsx`, `requestService.ts`, `RequestRepository.ts`):** Added `hasOwnField`, `getFieldValue`, `createFieldRecord` (`Object.create(null)`), and `setFieldValue` so `Object.prototype` properties (`constructor`, `toString`, `valueOf`, `hasOwnProperty`) never activate `matchesCondition` or `applicableFields` and hidden dependencies remain unset downstream. Converted `fields` to plain own-property objects at the Drizzle persistence boundary in `RequestRepository.Create`/`Patch`.
4. **`B04` — Typed `IN` membership controls (`apps/web/app/modules/admin/requestTypes/ConditionBuilder.tsx`):** Removed comma-splitting `InValueInput` and replaced it with `InValueControl` providing `Yes (true)`/`No (false)` checkboxes for `BOOLEAN`, option checkboxes for `SELECT`, and per-literal multi-value inputs with `Add value`/remove controls for `TEXT`, `TEXTAREA`, `DECIMAL`, and `DATE` (preserving comma-containing literals).
5. **`B05` — Locale-aware exact decimal currency formatting (`packages/contracts/src/requestTypes.ts`, `LineItemsEditor.tsx`, `RequestWizard.tsx`, `RequestResult.tsx`):** Added `formatMoney(amount, currency, locale)` using `BigInt` whole-part grouping and `Intl.NumberFormat.formatToParts` to render localized currency without converting canonical decimal strings to IEEE-754 floats.
6. **`B06` — E2E rejection of missing conditionally required fields (`e2e/configurable-forms.spec.ts`):** Extended the Playwright E2E flow to verify hidden-key `422` zero DB rows, client validation alert + `aria-invalid` + focus on missing conditionally required `Urgent reason`, incomplete draft save, server `422 VALIDATION_ERROR` rejection on submit (`REQUIRED`) and whitespace patch (`INVALID_VALUE`) with zero database mutation (`requests`, `approvalCycles`, `requestAuditEvents` unchanged), and localized currency formatting across wizard, result, and detail views.
